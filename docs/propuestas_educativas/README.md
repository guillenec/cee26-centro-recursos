## Para que sirve esta carpeta

- Centralizar propuestas pedagogicas reutilizables.
- Compartir recursos TIC con enfoque practico.
- Dejar materiales que puedan ampliarse con nuevas experiencias institucionales.

## Sugerencia de uso

1. Revisar la propuesta que mejor se ajuste a la necesidad del estudiante o grupo.
2. Adaptar actividades, herramientas y criterios segun el contexto pedagogico.
3. Incorporar nuevas propuestas en subcarpetas con su propio `README.md`.
